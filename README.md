## ✦ Featured Project

<div align="center">

### 🧪 Study Lab
**Plan the day. Focus deep. Track every chapter. Learn from every mock.**

</div>

Ek single-page, dark-themed study dashboard jo JEE preparation ke liye banaya hai. Koi backend nahi, koi framework nahi, koi build step nahi. Bas **HTML, CSS aur Vanilla JS**.

| | |
|---|---|
| 📅 **Plan** | Daily planner, week view, inbox aur targets board |
| ⏱️ **Focus** | Flow, Pomodoro aur Custom timers, streaks aur 7 ranks (Novice se Ascended) |
| 📚 **Track** | Chapter-wise syllabus tracker, lectures, DPPs, revisions aur PYQs |
| 📈 **Analyse** | Mock-test analytics, performance trajectory chart aur subject strength |
| 🪪 **Share** | Daily Card aur Test Card, flip karke PNG export kar sakte ho |
| ⏳ **Reality Check** | Exam tak bache din, live clock aur "agar 2 ghante waste kiye to kitne prep hours gaye" |

**Built with:** `HTML5` · `CSS3` · `Vanilla JavaScript` · `Shadow DOM` · `Canvas API` · `localStorage`
